# HoYoverse 登入驗證頁

這是 Discord 機器人 **MiHoYo GiftCode AutoRedeem** 的人機驗證頁面。

當你用帳號密碼向機器人註冊 HoYoverse 帳號時，官方有時會要求完成一次人機驗證（geetest）。
機器人沒辦法代替你完成，所以會給你這一頁的連結，由你本人完成驗證後把結果貼回 Discord。

## 這一頁會做什麼

1. 從網址 `#` 後面讀取驗證題目（由機器人產生）
2. 顯示官方的 geetest 驗證元件讓你完成
3. 把通過後的結果顯示出來，讓你複製

## 這一頁不會做什麼

- **不會問你任何帳號資料** —— 沒有輸入框，不會要你的信箱、密碼或任何憑證
- **不會把資料送到任何地方** —— 驗證結果只顯示在畫面上等你自己複製，這個網站收不到
- **不會記錄你** —— 驗證題目放在網址的 `#` 片段裡，依照瀏覽器的設計，`#` 後面的內容根本不會送到伺服器，所以連伺服器日誌都不會留下

驗證結果是一次性的、幾分鐘內就失效的字串，單獨拿到它也沒有任何用處。

## 為什麼要獨立成一個 repo

GitHub Pages 需要 repo 是公開的，但機器人的主專案含有自動部署設定，不適合公開。
把這個純靜態頁面拆出來，兩邊就都能維持在正確的狀態。

這個 repo 只有一個 HTML 檔，沒有任何程式邏輯、沒有 GitHub Actions、也沒有任何機密資料。
